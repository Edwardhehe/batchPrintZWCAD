# 加长图图幅命名新增「倍数」格式（配置3）

## 背景

设置里的「加长图图名命名格式」预留了 6 个配置，目前只实现了配置1（分数）和配置2（小数），配置3～6 均为占位。加长图在文件名、图纸目录、CSV 中仍以 `A1+1/4` 这类加长量形式出现，用户难以直接看出实际图幅是标准图幅的多少倍。

本 PR 实现配置3，输出「图幅 x 放大倍数」形式，例如 `A1x1.25`。

## 改动内容

| 文件 | 改动 |
| --- | --- |
| `src/Common/Models/AppSettingsStore.cs` | 枚举 `Reserved2` 更名为 `Multiplier`，占位值仍为 `2` |
| `src/Common/Utilities/FileNameSanitizer.cs` | `NormalizeLongPaperFraction` 新增倍数分支，并抽出 `FormatMultiplier` |
| `src/Common/Views/SettingsForm.xaml.cs` | 配置3 下拉项文案由「预留」改为倍数示例 |

共 3 个文件，42 行新增、6 行修改。

## 转换行为

倍数 = 1 + 加长量，即总长相对标准图幅长边的倍数。

| 输入 | 配置3 输出 |
| --- | --- |
| `A1+1/8` | `A1x1.125` |
| `A1+1/4` | `A1x1.25` |
| `A1+1/2` | `A1x1.5` |
| `A1+3/4` | `A1x1.75` |
| `A1+0.25` | `A1x1.25` |
| `A1+1` | `A1x2` |
| `A0`、`A1` 等标准图幅 | 原样返回 |
| `A1+1.501`（任意加长） | `A1x2.501` |

## 实现说明

- 扩展量有两种来源：`OutputPaperNameResolver.Resolve` 返回的 `+0.25` 小数形式，以及从图纸中读到的 `+1/4` 分数形式。两条路径都做了处理。
- 精度使用 `0.###`，覆盖 1/8 模数（0.125）而不产生多余尾零；比原计划的 `0.##` 更准确（`0.##` 会把 `A1+1/8` 截成 `1.13`）。
- 使用 `LongPaperNumberExtPattern`（`\+(\d+(?:\.\d+)?)$`）而非原有仅匹配小数的正则，使 `A1+1` 这类整数加长同样输出 `A1x2`。
- 原有配置1、配置2 的行为完全未变：仅将局部变量 `result` 更名为 `resultDefault`，用于和新增的倍数分支区分。
- 枚举值 `2` 保持不变，已保存 `Settings.json` 的用户升级后配置不会错位。

## 验证

已对转换逻辑做 11 个用例的验证，全部通过：

```
PASS  A1+1/4       -> A1x1.25
PASS  A1+1/8       -> A1x1.125
PASS  A1+1/2       -> A1x1.5
PASS  A1+3/4       -> A1x1.75
PASS  A1+0.25      -> A1x1.25
PASS  A2+0.75      -> A2x1.75
PASS  A1+1         -> A1x2
PASS  A1+2         -> A1x3
PASS  A1           -> A1
PASS  A0           -> A0
PASS  A1+1.501     -> A1x2.501
```

三个平台（ZWCAD、AutoCAD 2015–2024、AutoCAD 2025–2027）均可正常编译。
