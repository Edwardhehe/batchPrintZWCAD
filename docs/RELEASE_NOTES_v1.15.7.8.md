# 批量打印插件 v1.15.7.8 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。相对 **v1.15.7.7** 的更新如下。

## 相对 v1.15.7.7 的更新

### 打印样式线宽修复

- 修复不勾选「打印对象线宽」时 CTB 中的线宽不生效（只有颜色生效、线宽不按 CTB 输出）的问题：选了打印样式表时始终打开“打印线宽”，按 CTB 的线宽出图。
- 勾选「打印对象线宽」时颜色、淡显、线型等仍按 CTB，线宽按对象/图层线宽（行为不变）。
- 出图时关闭“缩放线宽”，线宽不再随布局设置按打印比例缩放。
- 正式打印、预览、多文件、合并 PDF、DWG 拆图等所有出图路径统一生效；设置窗口中该选项的说明文字同步更新。

### 临时红框与高亮

- 录入图框时的临时标签改用可显示中文的已有文字样式并居中，去掉字高上限。
- 通用型批量打印的红框序号按打印顺序编号，与列表编号列一致。
- 通用型高亮跟随选中行与键盘上下移动，且只画当前图的红框。
- 序号字高按框宽和字数限制，长图号不再溢出红框。
- 打印过程中不再改动 CAD 高亮。
- 高亮黄框宽度为红框的 1.3 倍，线宽同档。
