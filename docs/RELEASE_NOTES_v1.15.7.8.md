# 批量打印插件 v1.15.7.8 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。v1.15.7.7 的全部内容已合并到本版本，相对 **v1.15.7.6** 的更新如下。

## 相对 v1.15.7.6 的更新

### 打印对象线宽与 CTB 线宽

- 不勾选「打印对象线宽」时按所选打印样式表（CTB）的线宽出图：选了打印样式表时始终打开“打印线宽”（修复 v1.15.7.7 中不勾选时 CTB 线宽不生效、只有颜色生效的问题）。
- 勾选「打印对象线宽」时颜色、淡显、线型等仍按 CTB，线宽按对象/图层线宽：出图时自动生成并使用所选 CTB 的临时副本（原名`__objlw.ctb`），副本中所有线宽改为“使用对象线宽”，不修改原 CTB；线宽为“默认”的对象按 CAD 默认线宽（LWDEFAULT，通常 0.25mm）出图。
- 出图时关闭“缩放线宽”，线宽不再随布局设置按打印比例缩放。
- 正式打印、预览、多文件、合并 PDF、DWG 拆图等所有出图路径统一生效；设置窗口在该选项下方增加说明文字，打印日志中写入样式表管道诊断信息。

### 多文件批打

- 支持按文件夹收集 DWG 批量打印。
- 空间选择对话框增加「当前布局 / 仅模型 / 仅布局」快速勾选。
- 多文件批打时，带 UCS 的模型空间图框不再打斜：出图前按图框四角或文档 UCS 对齐视图扭转角，当前图批打、预览与外部文件路径统一准备视图。

### 合并 PDF 与进度

- 修复合并 PDF（尤其只有一张图时）完成提示框被置顶的进度窗挡住、导致界面卡住的问题：提示框指定属主，并先关闭进度窗。
- 修正单张打印时的进度条显示。
- 合并后的 PDF 文件名增加「_合并」后缀。

### DWG 拆图

- 模型空间拆图改为 Wblock 克隆框内实体并加 XClip 裁剪边界写入新 DWG，不再整图复制后删除框外对象；布局拆图逻辑不变。
- 拆图保存后先恢复原工作数据库再释放新库，提升稳定性。

### 临时红框与高亮

- 录入图框时的临时标签改用可显示中文的已有文字样式并居中，去掉字高上限。
- 通用型批量打印的红框序号按打印顺序编号，与列表编号列一致。
- 通用型高亮跟随选中行与键盘上下移动，且只画当前图的红框。
- 序号字高按框宽和字数限制，长图号不再溢出红框。
- 打印过程中不再改动 CAD 高亮。
- 高亮黄框宽度为红框的 1.3 倍，线宽同档。

### 设置与界面

- 设置窗口中的线宽选项回读生效。
- 图框录入提示可手动调整打印范围。
- 通用型批量打印窗口去掉「右键条目可设为不打印、删除或批量改纸张」提示文字。

### 加长图图幅命名

- 设置中加长图图幅命名新增「配置3（倍数）」：A1+1/4 输出 `A1x1.25`，A1+1 输出 `A1x2`。
- 按长边倍数计算，标准图幅命名不变。
