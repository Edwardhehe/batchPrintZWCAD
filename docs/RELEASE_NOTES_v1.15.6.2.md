# 批量打印插件 v1.15.6.2 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。打印样式会记住上次选择，图框块与矩形框清单更干净，改纸张时不再整批重画 CAD 红框。

## 打印样式

- 图框块批打、矩形框批打和单张打印共用上次选择的 CTB。
- 打开窗口按文件名恢复上次样式；列表里暂时没有该文件时仍显示上次选择，不会回落到 `monochrome` 把记录冲掉。
- 在下拉里更换 CTB 后立即写入设置。

## 图框块清单

- 「添加 DWG」改名为「多文件批打」。
- 重复图号、重复图名在清单中标红；去掉单独的「图号图名检查」按钮。
- 去掉「实际尺寸」「输出纸张」两列，纸张匹配和打印仍使用这些数据。

## 矩形框清单

- 去掉「图形尺寸」列。
- 改纸张、切换输出格式时不再整批重建 CAD 红框；只有框集合或打印序号变化时才重画。
