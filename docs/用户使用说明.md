# 批量打印插件用户使用说明

版本：v1.11.2

本插件用于中望 CAD 和 AutoCAD 的图纸批量打印。它可以识别图框、提取图号和图名、自动匹配纸张与比例，并批量输出 PDF。插件也支持矩形框批量打印、单张框选打印、PDF 合并、批量拆图、图纸目录生成和 PDF 文件整理。

## 支持范围

- 中望 CAD：ZWCAD x64。
- AutoCAD 2019-2020：使用 `AutoCAD2019-2020` 包。
- AutoCAD 2021-2024：使用 `AutoCAD2021-2024` 包。
- AutoCAD 2025 及以后：使用 `AutoCAD2025之后` 包。

请按自己的 CAD 版本选择对应文件夹中的 DLL。AutoCAD 2019 用户不要加载 2021-2024 包，AutoCAD 2024 用户不要加载 2019-2020 包。

## 安装和打开

推荐安装方式：

1. 关闭 CAD。
2. 解压对应版本的发布包。
3. 双击包内的 `安装.cmd`。
4. 重新打开 CAD。
5. 菜单栏中会出现“批量打印”菜单。

手动加载方式：

1. 打开 CAD。
2. 输入 `NETLOAD`。
3. 选择对应 DLL：
   - 中望 CAD：`BatchPlotter.dll`
   - AutoCAD 2019-2024：`AcadBatchPlot.dll`
   - AutoCAD 2025 及以后：`AcadBatchPlot.Core.dll`
4. 加载后可使用命令或菜单打开功能。

常用命令：

- `ZBP_SHOW_PANEL`：打开批量打印主界面。
- `ZBP_RECTANGLE_BATCH_PLOT`：矩形框批量打印。
- `ZBP_SINGLE_PLOT`：单张框选打印。

## 功能总览

### 1. 图框库批量打印

适合图纸中使用统一图框块的项目。

主要能力：

- 建立图框库，记录常用图框块。
- 识别图框范围、图号、图名和图幅。
- 扫描当前图或批量添加多个 DWG 文件。
- 自动生成打印清单。
- 支持修改清单中的图号、图名。
- 支持按清单批量输出 PDF。
- 支持合并为一个 PDF。
- 支持生成图纸目录。
- 支持批量拆图为单独 DWG。

基本流程：

1. 点击“新增图框”，按提示选择图框块、打印外框、图号区域和图名区域。
2. 打开“批量打印”。
3. 扫描当前图，或添加多个 DWG 文件。
4. 检查识别结果，包括图号、图名、图幅、比例和输出文件名。
5. 选择输出目录、PDF 绘图仪和打印样式。
6. 点击“开始打印”。

### 2. 矩形框批量打印

适合没有标准图框块，但每张图纸外框是矩形的项目。

主要能力：

- 不需要提前建立图框库。
- 框选一个扫描范围，自动识别范围内的矩形图框。
- 按图纸位置自动排序。
- 在图中显示临时红框和序号，方便核对顺序。
- 可手动调整是否打印、输出纸张和打印顺序。
- 支持单页 PDF 或合并 PDF。

基本流程：

1. 点击“矩形框批量打印”。
2. 框选需要扫描的图纸范围。
3. 检查识别出来的图框列表。
4. 必要时调整纸张、顺序和勾选状态。
5. 点击打印。

### 3. 单张框选打印

适合临时打印一张图。

主要能力：

- 手动框选图纸外框。
- 自动判断纸张和比例。
- 可预览。
- 可直接输出 PDF。

基本流程：

1. 输入 `ZBP_SINGLE_PLOT` 或点击“单张打印”。
2. 选择图纸外框两个对角点。
3. 确认纸张、比例和保存位置。
4. 预览或打印。

## PDF 功能

### 合并 PDF

批量打印时勾选“合并为单个 PDF”，插件会先打印临时单页 PDF，再合并为一个总 PDF。合并成功后会保留最终 PDF。

### PDF 工具

PDF 工具可用于：

- 添加多个 PDF。
- 添加整个文件夹中的 PDF。
- 按自然顺序排序。
- 手动上移、下移调整顺序。
- 合并 PDF。
- 给 PDF 文件名批量加序号。
- 批量替换文件名文字。
- 撤回上一次批量改名。

## 批量拆图

在批量打印识别出图框后，可以使用“批量拆图”。

插件会按图框把图纸拆成单独 DWG 文件，文件名沿用图号和图名。模型空间图纸会输出轻量的新 DWG；布局空间图纸会保留相关布局内容。

输出目录通常为源 DWG 所在目录下的 `DWG` 子目录。

## 生成图纸目录

识别出图框清单后，可以生成图纸目录。

目录列包括：

- 序号
- 图号
- 图名
- 图幅
- 备注

可在“设置”中调整目录表格的列宽、行高、文字高度比例和文字样式。

## 设置

设置中可以调整：

- 默认输出目录。
- PDF 文件名连接符。
- PDF 已存在时是否自动加序号。
- 是否跨文件打开 DWG 打印。
- 图纸目录列宽、行高和文字样式。
- 打印清单和输出命名规则。

## 绘图仪和纸张

插件会自动安装或生成专用 PDF 绘图仪：

- 中望 CAD 使用 `LA_pdf.pc5` 和对应 PMP。
- AutoCAD 使用 `LA_pdf.pc3` 和对应 PMP。

用户一般不需要手动配置绘图仪。首次加载插件时，它会把所需文件写入当前 CAD 用户配置目录。

支持常用 A0、A1、A2、A3、A4，以及加长图纸。遇到非常规尺寸时，插件会尝试按图框尺寸匹配或生成用户纸张。

## UCS 支持

插件支持用户坐标系 UCS。模型空间中旋转 UCS 后扫描、红框标注、预览和打印会尽量保持一致，不需要把图纸手动转回 WCS。

## 常见提示

- 如果刚加载新 DLL 后界面没有变化，请关闭 CAD 后重新打开再加载。CAD 通常会锁定已加载的 DLL。
- 如果菜单没有出现，可以输入 `ZBP_SHOW_PANEL` 打开主界面。
- 如果 PDF 已存在，可在设置里选择覆盖或自动加序号。
- 如果识别结果不对，先确认图框是否在关闭、冻结或不打印图层上。
- 如果矩形框识别太多或太少，缩小框选范围通常更容易得到正确结果。
- 如果 AutoCAD 提示找不到命令，可重新运行安装脚本，或重新 `NETLOAD` 对应版本 DLL。

## 卸载

关闭 CAD 后，双击发布包中的 `卸载.cmd`。卸载会移除自动加载配置。用户自己的图纸文件不会被删除。
