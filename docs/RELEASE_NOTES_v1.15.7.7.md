# 批量打印插件 v1.15.7.7 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。相对 **v1.15.7.6** 的更新如下。

## 相对 v1.15.7.6 的更新

### 打印对象线宽

- 设置中勾选「打印对象线宽」后，出图时自动生成并使用所选 CTB 的临时副本（原名`__objlw.ctb`），副本中所有线宽改为“使用对象线宽”，不修改原 CTB。
- 样式表中的颜色、淡显、线型等照常生效，只有线宽改按对象/图层线宽打印；线宽为“默认”的对象按 CAD 默认线宽（LWDEFAULT，通常 0.25mm）出图。
- 不勾选时完全按所选打印样式表出图。
- 设置窗口在该选项下方增加说明文字，并在打印日志中写入样式表管道诊断信息。

### 多文件批打

- 支持按文件夹收集 DWG 批量打印。
- 空间选择对话框增加「当前布局 / 仅模型 / 仅布局」快速勾选。
- 多文件批打时，带 UCS 的模型空间图框不再打斜：出图前按图框四角或文档 UCS 对齐视图扭转角，当前图批打、预览与外部文件路径统一准备视图。

### 合并 PDF 与进度

- 修复合并 PDF（尤其只有一张图时）完成提示框被置顶的进度窗挡住、导致界面卡住的问题：提示框指定属主，并先关闭进度窗。
- 修正单张打印时的进度条显示。
- 合并后的 PDF 文件名增加「_合并」后缀。

### DWG 拆图

- 模型空间拆图改为 Wblock 克隆框内实体并加 XClip 裁剪边界写入新 DWG，不再整图复制后删除框外对象；布局拆图逻辑不变。
- 拆图保存后先恢复原工作数据库再释放新库，提升稳定性。

### 设置与界面

- 设置窗口中的线宽选项回读生效。
- 图框录入提示可手动调整打印范围。
- 通用型批量打印窗口去掉「右键条目可设为不打印、删除或批量改纸张」提示文字。

### 加长图图幅命名

- 设置中加长图图幅命名新增「配置3（倍数）」：A1+1/4 输出 `A1x1.25`，A1+1 输出 `A1x2`。
- 按长边倍数计算，标准图幅命名不变。
