# 批量打印插件 v1.15.6.3 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。修复打印样式在换机/换版本后失效的回退，并改进 AutoCAD 打印机配置搜索路径的解析。

## 打印样式

- 仍记住上次选择的 CTB，并在各打印窗口共用。
- 若当前 CAD 列表中找不到上次样式（文件已删，或切换 CAD 版本后没有同名 CTB），自动改选现有可用样式，优先 `monochrome`，再取列表第一项，并更新记忆值。
- 不再把失效的样式名硬插进下拉框。

## AutoCAD 绘图仪目录

- 安装 `LA_pdf` 等配置时，读取选项中的**全部**打印机配置搜索路径，不要求必须是第一项。
- 只要默认 `ROAMABLEROOTPREFIX\Plotters` 仍在搜索路径中且目录存在，优先写入该默认目录。
- 关联/修正 PMP 时，允许修改位于任一搜索路径目录内，或当前 CAD 用户配置根目录内的 `LA_pdf.pc3`。
- 减轻「一出图」等第三方工具额外挂接打印机目录后，仅因排序靠前就装错目录或误拦关联的问题。
