# 批量打印插件 v1.14 发布说明

发布日期：2026-07-27

## 主要更新

- 重构矩形框扫描流程，大图纸、多布局和嵌套块中的矩形识别速度与稳定性进一步提升。
- 除闭合多段线外，可在常规设置中选择识别由四条直线或直线型开放 PL 严格首尾相连组成的矩形框。
- 完善矩形框的可见性、图层和内容过滤：允许识别位于 `Defpoints` 等不打印图层上的可见边框，但不把不打印图层内容输出到图纸。
- 矩形框纸张识别改为以物理短边确定图幅，并完善标准纸、1/8 模数加长纸及任意加长纸的匹配和批量注册。
- 图框块批打与矩形框批打统一支持正、负留白：正值扩大纸张并保持原比例，负值保持纸张并居中缩小内容。
- 加长图幅名称支持小数与分数双向规范化，避免文件名中的斜杠影响保存、分组和 PDF 合并。
- 图号重排和排序界面重构，支持前缀、后缀、起始号、自动识别及空间顺序预览。
- 临时红框与打印清单同步增强，可直接在 CAD 中删除红框并同步移除对应任务。
- 图框块批量打印、矩形框批量打印和单张打印统一显示并记住 CTB；可直接点击“设置”打开当前打印样式。
- 两个批量打印主窗口重新整理常用操作区域，并在标题中明确显示 `V1.14`。
- 修复高 DPI 下“输出 / 输出格式 / CTB”“设置”“开始打印”等文字被裁剪的问题，并统一留白控件与保存路径控件的高度。
- 保持三个发布兼容组：ZWCAD、AutoCAD 2015–2024、AutoCAD 2025–2027。

## 兼容范围

| 平台 | DLL | 兼容范围 |
|------|-----|----------|
| ZWCAD | `BatchPlotter.dll` | ZWCAD Enterprise x64 |
| AutoCAD | `AcadBatchPlot.dll` | AutoCAD 2015–2024 |
| AutoCAD Core | `AcadBatchPlot.Core.dll` | AutoCAD 2025–2027 |

AutoCAD 2015–2024 全系列共用同一个 DLL；AutoCAD 2025–2027 全系列共用同一个 Core DLL。

## 本地发布包

- `ZwcadBatchPlot-v1.14.zip`
- `AcadBatchPlot-AutoCAD2015-2024-v1.14.zip`
- `AcadBatchPlot-AutoCAD2025-2027-v1.14.zip`

安装前请关闭 CAD，并完整解压对应压缩包后运行 `安装.cmd`。不要只复制主 DLL，以免遗漏依赖文件、安装脚本或绘图仪资源。
