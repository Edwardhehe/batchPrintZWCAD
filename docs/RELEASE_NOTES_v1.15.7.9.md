# 批量打印插件 v1.15.7.9 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027，相对 **v1.15.7.8** 的更新如下。

## 相对 v1.15.7.8 的更新

### 通用型批打：智能识别图名图号

- 通用型批量打印窗口底部新增「按已录入图框最多的模式智能识别图名图号」勾选（默认关闭）：用图框库里数量最多的那种模式，按本张图的实际比例，把图名、图号区域放到图纸右下角取字。勾选后从下一次扫描生效；勾选期间改纸张会按新图幅再取一次图名图号。
- 图框旋转时沿用图框块扫描的块内右下角作为基点，不再按世界坐标右下角取错字。
- 图框库管理新增「识别图框模式」：按纸张 1:1 比较图名、图号角点相对图纸右下角的位置并归类（相差 1mm 以内视为同一模式），同一套图框的 A2、A3 只要右下角关系一致就归为同一模式。
- 智能识别取字改为按格子局部坐标判定，支持旋转/镜像图框：文字中心在格内或重叠 ≥55% 才算命中，只压在边线上的文字不再被取到；有包围盒的属性以包围盒为准。
- 通用型取字不再把块名当成文字，签字栏、LOGO 等块名不会再拼进图号；图框型批打不受影响。

### 通用型批打：文件名设置

- 底部按钮行在「排序设置」与「常规设置」之间新增「文件名设置」，与图框型一致，打开设置窗口的「文件名」页，命名规则与图框型共用。
- 确定后，识别到图号/图名的行按规则命名，其余仍为「DWG名+序号」。

### 打印管线预热，消除首张打印卡顿

- 批打窗口（图框型/通用型）打开后、切换输出格式或打印样式时，在空闲时分步预热打印引擎、设备纸张目录、打印样式表和绘图驱动（向临时目录打一张空白小图后删除），每个设备+样式组合每次会话只预热一次；DWG 输出跳过预热。
- 开始批打前若分步预热未完成，会同步补齐，不会在批打中途插入预热动作。
- AutoCAD 关闭自动打印日志（AutomaticPlotLog，不支持时自动跳过）；纸张目录改为按设备与模型/布局枚举。
- 感谢 @dangfj110 贡献（PR #23）。

### 设置保存与多文件批打

- 设置文件被占用时自动重试，仍失败则弹窗提示，不再导致 CAD 崩溃；设置、图框库、比例设置、图纸目录等保存统一改为原子写入。
- 批打窗口打开时只在设置有变化时才写回设置文件。
- 多文件批打改为累加清单：只替换本次成功重扫的「文件 + 空间」，不再清空已有清单。
- 通用型批量打印窗口删除「重新识别」按钮。

### 输出文件命名

- 合并 PDF 始终避开已有文件（自动加 _1、_2…），不再覆盖上一次的合并结果。
- 同一批内重名的输出文件全部按清单顺序从 _1 开始编号（图号_1、图号_2…），图框型、通用型批打和 DWG 拆图一致。
