# 批量打印插件 v1.15.5 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027，重点改进带可见性属性的动态图框识别，并允许固定图框按任意比例选定纸张。

## 动态块可见性图框

- 带可见性属性的动态块按“块名+当前可见性名”录入图框库，例如 `地铁图框+A2`。
- 同一动态块的不同可见性状态作为不同图框分别识别，不再互相覆盖。
- 录入时需切换到对应可见性后再新增；扫描时按当前可见性匹配已入库定义。
- 可自由拉伸、查寻加长的动态块仍按块名入库，扫描时按当前实例实际长度识别纸张。
- 旧图框库中的“外层+内层块名”记录仍可识别。

## 任意比例选纸

- 常用比例匹配失败、但长宽比仍接近标准图幅或 1/8 模数加长图时，固定图框和单张打印可选择目标图幅，再按所选尺寸反推比例。
- 可自由拉伸动态块不走该分支，避免把拉伸长度误当成任意比例。
