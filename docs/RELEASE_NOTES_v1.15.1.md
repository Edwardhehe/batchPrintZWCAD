# 批量打印插件 v1.15.1 发布说明

本版本为本地发布版本，覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。

## 图框块批量打印

- 排序设置新增“按图号排序”和“按图纸位置排序”两种模式。
- 按图号排序时，图号和图名都相同的图纸会自动按图中位置排序。
- 按图纸位置排序时完全忽略图号、图名，并支持“从上到下、从左到右”或“从左到右、从上到下”。
- 不同 DWG、不同布局分别处理，避免跨图形或跨布局直接比较坐标。
- 矩形框批量打印继续固定按图中位置排序。

## 图号重排与表格编辑

- 图号重排窗口直接提供空间顺序选择，并支持自动或固定图号位数。
- 多布局图号重排按布局选项卡顺序处理，再按布局内位置生成图号。
- 图号、图名改为双击进入编辑，单击只选择和高亮图纸。
- 编辑结束后，对应 DWG 已打开时同步反写 CAD；图号变化会同步刷新排序、文件名和临时红框序号。

## 图框识别与图框库

- 支持可自由拉伸图框的录入、识别和实际长度计算。
- 修复部分加长拉伸块被误判为可见性切换，导致无法识别实际长度的问题。
- 图框库管理中会标识当前 CAD 已存在的图框，方便核对和编辑。
