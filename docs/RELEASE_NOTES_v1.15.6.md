# 批量打印插件 v1.15.6 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027，重点加速图框识别与批打窗口刷新，并减轻打开、关闭窗口时的卡顿。

## 图框识别加速

- 扫描期间缓存块名、块定义文字和图框几何，同一块定义不再重复展开文字或计算图框。
- 布局内块参照的包围盒只计算一次，重叠图签查找不再对每个字段遍历整图。
- 文字提取路径保持完整，识别结果与上一版本一致，仅减少重复计算。

## 批打窗口与红框

- 图框、矩形窗口表格改为整批刷新，识别过程中不再逐行触发界面重绘。
- 选中图纸时的临时红框改为屏幕刷新，不再整图重生；延迟绘制仅在窗口句柄已创建后执行，避免打开矩形窗口时报错。
- 关闭窗口时按已记录的红框 ID 删除，不再全图扫描图层，关闭更快。
- 矩形框窗口顶部栏按内容自适应高度，提示文字不再被裁切；点选行高亮与列头排序改为整批更新。
