# 批量打印插件 v1.15.4 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027，重点改进按图框拆分 DWG，并修正“不打印外边框”的裁切方式。

## DWG 拆图

- 拆图改为先另存源图副本，再只删除当前图框外的对象，不再使用 `Wblock` 整库克隆，避免视口关闭、UCS 错位或拆出空图。
- 模型拆图只清理模型空间，不删除纸面布局，避免 CAD 打开拆出文件时报错。
- UCS 图框在用户坐标系内判定去留，窗口用实际角点而不是四角世界包围盒，减少斜框漏图和邻框误入。
- 带 XCLIP 的块按裁剪框与图框打印范围是否相交决定去留，不看插入点或未裁剪外包。
- 与图框相交的图元予以保留，包括穿框填充、块、图像和骑框视口；只贴边的邻框仍不带入拆出文件。
- 未保存图纸仍需先保存。副本只包含磁盘上的已保存内容。

## 不打印外边框

- 勾选后改为按纸面四边各内退 1mm 裁切打印内容，选纸、比例和留白仍按原窗口计算。
- 不再把图框临时移到不打印层，停止打印时也不会改写 DWG。
