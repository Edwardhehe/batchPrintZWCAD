1. 先下载正确的版本

不同 CAD 版本加载的 .NET 运行时不同，所以发布包按平台拆开。先确认自己的 CAD 版本，再下载对应 zip。

ZWCAD

中望 CAD

当前主要面向 ZWCAD 2025 x64。

下载：ZwcadBatchPlot-v*.zip

加载 DLL：BatchPlotter.dll

AutoCAD

AutoCAD 2019-2020

对应 .NET Framework 4.7。

下载：AcadBatchPlot-AutoCAD2019-2020-v*.zip

加载 DLL：AcadBatchPlot.dll

AutoCAD 2021-2024

对应 .NET Framework 4.8。

下载：AcadBatchPlot-AutoCAD2021-2024-v*.zip

数据位置

配置会保留

图框库、设置、日志默认保存在用户 AppData 目录。卸载插件不会删除这些用户数据。

建议

优先用安装脚本

普通用户推荐双击 安装.cmd，以后 CAD 启动自动加载。临时测试才用 NETLOAD。

2. 安装和卸载

安装前建议关闭 CAD。安装完成后重新打开 CAD，菜单栏会出现“批量打印”。AutoCAD 2025+ 如果菜单栏没有出现，可以执行命令 ZBP_SHOW_PANEL 打开主界面。

下载并解压对应 zip 把压缩包解压到一个固定目录，不要直接在压缩包里双击运行。
关闭 CAD，双击 安装.cmd 脚本会复制插件文件，并写入当前用户的自动加载注册表项。
重新打开 CAD 菜单栏出现“批量打印”后即可使用。也可以执行 ZBP_SHOW_PANEL 打开批量打印窗口。
卸载 关闭 CAD 后双击 卸载.cmd。如果 CAD 正在运行，插件文件可能无法删除，关闭 CAD 后再执行一次即可。

手动加载方式：在 CAD 中执行 NETLOAD，选择对应 DLL。旧版本 DLL 已加载时，建议重启 CAD 后再加载新 DLL。

3. 第一次批量打印

第一次使用的核心是先让插件认识你的图框块。图框入库后，后续同名图框会自动识别图号、图名、图幅和打印范围。

新增图框 菜单栏点击“新增图框”，选择图框块，按提示框选打印边界、图名区域、图号区域，并确认输出纸张。
打开批量打印窗口 点击“批量打印”，先试“扫描当前图”。只想识别局部时用“框选扫描”。
检查清单 检查图号、图名、图幅、比例、空间和输出 PDF。可以直接在表格里改图号、图名。
选择输出和打印机 输出路径可选“当前文件夹”“当前文件夹/PDF”或“指定文件夹”。打印机选择 CAD PDF 打印机，CTB 选择需要的样式。
开始打印 勾选需要打印的行，点击“开始打印”。生成文件名默认类似 图号_图名.pdf。

4. 图框信息库

图框库是批量打印稳定识别的基础。一个图框块入库后，可以长期复用；图框库支持导入导出，方便在多台电脑之间迁移。

新增图框时要框选什么

打印外边界、图名区域、图号区域。图名和图号区域内的真实文字会被读取，MText 格式码会被清理。

纸张尺寸怎么确定

新增图框时会自动给出默认图幅，用户可以修改。以后该块名默认按这个纸张尺寸输出。

什么时候用图框库管理

块名、图幅、纸张尺寸、打印边界不对时，打开“图框库管理”直接修改，比重新新增更快。

5. 生成图纸目录

识别图框后，点击“生成目录”，在当前 CAD 中指定目录左上角基点，插件会生成表格。

目录表头

序号、图号、图名、图幅、备注

目录内容来自当前批量打印清单，所以生成前先检查图号、图名、图幅是否正确。

目录样式设置

在“设置 -> 图纸目录”中可设置列宽、行高、文字高度比例和文字样式。也可以从 CAD 框选单元格尺寸。

6. 批量 CAD 拆图

拆图会按当前勾选清单输出单独 DWG，文件名使用图号和图名。适合给外部单位、审图或归档时拆分总图纸文件。

模型空间

生成轻量新 DWG

只复制图框范围内或与图框相交的对象。块对象按实际显示外包框判断，不按块基点判断。拆出的 DWG 打开后自动把图框居中并尽量全屏显示。

布局空间

保留原模型空间

布局图纸不会裁剪模型空间。插件会复制原 DWG，只保留目标布局，并清理该布局图框外图素。

输出位置为每个源 DWG 所在目录下的 DWG 子目录。拆图前建议先保存源 DWG。

7. PDF 工具

批量打印后可以直接打开 PDF 工具检查成果，也可以手动添加 PDF 或整个文件夹。

跨文件阅读

支持上一份、下一份、自然排序和手动上移下移，适合快速检查批量输出结果。

合并 PDF

可将多个 PDF 合并，并按源 PDF 文件名生成书签。

批量改名

支持批量加编号、替换文件名文字，并可撤回上一次批量改名。

常见问题

安装后没有看到菜单怎么办？

先确认下载包是否匹配 CAD 版本。AutoCAD 2025+ 如果菜单栏没有显示，执行 ZBP_SHOW_PANEL 打开主界面。也可以执行 NETLOAD 手动加载对应 DLL。

为什么要分这么多 AutoCAD 包？

AutoCAD 2019-2020、2021-2024、2025+ 使用的 .NET 运行时和 CAD 托管 API 不同，一个 DLL 很难稳定通吃，所以按版本发布最稳。

图框识别错了怎么办？

打开“图框库管理”，检查块名、图幅、纸张尺寸、打印边界、图名区域、图号区域。必要时重新新增图框。

批量打印输出尺寸不对怎么办？

优先检查图框库里该块名绑定的图幅和纸张尺寸。插件按图框库里的固定输出纸张打印，而不是按 CAD 里图形实际放大比例直接输出巨大 PDF。

PDF 工具无法内嵌预览怎么办？

PDF 内嵌预览依赖 Microsoft Edge WebView2 Runtime。个别电脑无法预览时，可以安装 WebView2 Runtime，或使用外部打开方式检查 PDF。
