# 批量打印插件 v1.15.3 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027，重点增加图框块任意比例识别，并优化比例设置界面。

## 图框块任意比例

- 图框块批量打印不再受固定比例列表限制，按录入图框的纸张短边自动反推实际比例。
- 支持从标准纸张放大的 `1:xx` 比例，也支持缩小后的 `xx:1` 比例，例如 `1:100`、`10:1`、`2.1:1`。
- 对通过动态拉伸改变长边的图框，短边继续作为图幅和比例依据；长边只参与标准图幅、加长图幅及任意纸张判断。
- 加长图仍按 1/8 模数识别；不能合理吸附时按实测长边动态生成纸张。
- 兼容旧图框库中的非标准纸张名称和已录入的任意纸张尺寸。

## 比例设置界面

- 重新整理比例设置页，明确区分“图框块任意比例”和“矩形框比例列表”的作用范围。
- 矩形框批量打印仍只使用内置及自定义比例，不开放任意比例识别。
- 增加内置/自定义比例数量、选中状态和删除条件提示，支持回车快速添加比例。
- 保留从 CAD 图中拾取比例、批量选择及删除自定义比例的原有能力。
