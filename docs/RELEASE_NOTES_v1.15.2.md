# 批量打印插件 v1.15.2 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027，重点改善字体兼容、矩形框识别、UCS 打印和空间排序。

## 文字与日志设置

- 常规设置新增“文字自动转图形打印”，PDF/DWF 可把 TrueType 文字按图形输出，避免接收方缺少字体造成乱码、字距或换行异常。
- 文字转图形默认关闭，只影响插件自有 `LA_pdf` / `LA_dwf` 绘图仪，不炸开或修改原 DWG 文字；PNG/JPG 本身为图像输出，无需转换。
- 常规设置新增“生成打印日志”总开关，默认关闭；打印、拆图、扫描警告和图框诊断日志全部受该开关控制。

## 矩形框识别

- 实体自身 `Visible=False`、所在图层关闭/冻结或父块不可见时，不再生成矩形框打印任务。
- 可见的 Defpoints 等不打印图层仍可作为打印边界，避免因图层不参与打印而漏掉真实图框。
- 使用网友问题图纸后台验证：错误的隐藏图框任务由 28 个降为 26 个，隐藏句柄不再进入扫描结果。

## UCS、多布局与空间排序

- 矩形框和图框块在旋转 UCS 下统一使用实际选择范围，扫描、红框、预览和正式打印保持一致。
- 多布局按 CAD 布局选项卡 `TabOrder` 排列，再在各布局内部按位置排序。
- 修复不同尺寸图框相互搭桥时传递合并行列的问题，避免先排完整列后再跳回右侧图纸。
- 按位置排序继续完全忽略图号、图名和手动优先级。

## 其他改进

- 支持自定义打印比例，可手动添加或从图中拾取。
- 完善任意尺寸纸张、PDF 合并输出路径和快捷命令别名设置。
