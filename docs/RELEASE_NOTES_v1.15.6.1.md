# 批量打印插件 v1.15.6.1 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。修复装了实体打印机后批量输出 PDF 时弹出「无法连接到指定的打印机」的问题，并加固安装、自动加载与 AutoCAD 2025 依赖解析。

## 打印设备绑定

- 覆盖打印设置不再 `CopyFrom` 布局页面设置，避免 CAD 先去连接图纸里保存的系统打印机或 Windows 默认打印机。
- 正式打印直接绑定插件自有 `LA_pdf` / `LA_png` / `LA_jpg` / `LA_dwf`，与系统默认打印机无关。
- 仅在自定义纸张刚写入 PMP、需要刷新纸张目录时才先解绑 `None`。
- 去掉布局拷贝后，有 CTB 时显式打开「按样式打印」，避免 Screening 等打印样式失效。

## 安装与自动加载

- 安装脚本改为当前用户目录安装，避免以管理员身份运行后普通用户启动 CAD 看不到插件。
- 安装前检测 CAD 是否占用 DLL，并清除下载文件的互联网区域标记。
- 自动加载只写入当前这套 CAD，其它版本不会被连带改掉。

## AutoCAD 2025 依赖

- 从插件目录解析 Newtonsoft.Json 等私有依赖，避免与天正等插件抢同一份程序集导致无法加载图框库。
