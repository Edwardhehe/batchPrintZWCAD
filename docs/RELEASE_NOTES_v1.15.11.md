# LA批量打印插件 v1.15.11 发布说明

本版本相对 **v1.15.10.1** 的功能发布。适用于 ZWCAD、AutoCAD 2015–2024 与 AutoCAD 2025–2027。

## 相对 v1.15.10.1 的更新

### 打印签名、印章和二维码

- 图框库可为图框配置签章槽位和二维码位置；新增签名库、印章库，支持导入图片。
- 两个批打窗口在输出 PDF 时可勾选「打印签名」「打印印章」「打印二维码」。签名和印章默认开启，二维码默认关闭。
- 出图后对 PDF 一次性盖章；失败只记日志，不中断整批。槽位名带「章」走印章，否则走手写签名。
- 下拉菜单新增「二维码及签章」子菜单，相关命令收在下一级。
- 直接打到打印机没有 PDF 后处理，不会盖章；通用型批打若图纸没有已入库图框块名，也会跳过。

### 三点文字识别图签

- 通用型批打可通过三个锚点文字识别图名、图号等字段，不依赖图块名称；新增「三点图签信息库管理」。
- 识别成功后会打开清单中的图号、图名列，并进入属性命名。
- 「生成目录」可使用识别到的图号、图名；若图签中有图幅文字，图幅列会优先使用它。
- 在 UCS 下生成目录时，点击位置与表格插入位置已对齐。
- 录入三点图签时，若当前不是世界坐标系，会提示先切回 WCS。

### 其他

- 图框库「新增图框」在 AutoCAD 中不再先隐藏窗体，避免出现 Window is not active。
- 批打窗口样式与设置窗口对齐。

## 安装说明

与以往版本相同：按平台解压对应 ZIP，按说明 NETLOAD 或使用自动加载；升级时请先关闭已加载该 DLL 的 CAD 进程后再替换文件。
