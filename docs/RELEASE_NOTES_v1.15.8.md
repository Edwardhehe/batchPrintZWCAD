# 批量打印插件 v1.15.8 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。v1.15.7.1 – v1.15.7.9 的全部内容已合并到本版本，并新增天正文字读取修复（PR #24）。相对 **v1.15.7**（v1.15.7 最初版）的更新如下。

## 相对 v1.15.7 的更新

### 通用型批打（矩形框）

- 识别顶层块属性 Tag 为「图号」「图名」的非空值（同框取离右下角最近）；本批至少一张识别到属性时显示图号/图名列，文件名按命名规则生成，无属性的图框回退为「DWG名+序号」。
- 新增「按已录入图框最多的模式智能识别图名图号」勾选（默认关闭）：用图框库里数量最多的模式，按本张图的实际比例，到图纸右下角取图名、图号；勾选后从下一次扫描生效，勾选期间改纸张会按新图幅再取一次。图框旋转时以块内右下角为基点。
- 智能识别取字按格子局部坐标判定，支持旋转/镜像图框：文字中心在格内或重叠 ≥55% 才算命中，只压在边线上的文字不再被取到；有包围盒的属性以包围盒为准。取字不再把块名当成文字，签字栏、LOGO 等块名不会再拼进图号。
- 底部按钮行新增「文件名设置」，与图框型共用命名规则；确定后识别到图号/图名的行按规则命名。
- 多文件清单先按文件名分组排序；同一文件内有图号时按图号自然序，没有图号时按布局与空间顺序。
- 扫描失败时展示完整异常信息，便于反馈定位。
- 提供「清空清单」；删除「重新识别」按钮；去掉「右键条目可设为不打印、删除或批量改纸张」提示文字。

### 纸张识别与改纸

- 短边毫米匹配比例库；失败则按长宽比命中图幅并反推任意比例。
- 任意比例下展开 A0～A4 候选，可在下拉中改选其他标准图幅并自动换算比例。
- 批量改纸在候选不一致时，也可按同一套长宽比图幅名统一更换。

### 扫描与识别

- 面板「框选扫描」改为按对象选择（点选/框选），选择阶段即按类型过滤，只扫描选中对象；「扫描当前图」保留范围对话框，两者共用同一套候选对象过滤。
- 框选扫描未拾取时右键弹出扫描范围菜单（当前模型 / 所有布局 / 模型+布局 / 当前布局等）；已选择后右键确认选择。
- 框选/范围扫描结果累加到现有清单；扫描范围窗改为四个按钮直选。
- 扫描当前图 / 框选扫描时弹出可取消的识别进度窗，显示阶段与处理数量。
- 外框识别支持四线拼合：四条独立直线或开放多段线可拼成矩形，图框录入与矩形扫描共用同一套算法和容差。
- 天正文字（`TCH_TEXT` / `TCH_MTEXT`）读取改为在天正已加载时调用天正内核（tch_kernal.arx）接口取字与定位点，修复取图名图号时读不到天正文字；按实体类名识别天正文字，天正未加载时的代理实体会跳过，无法读取其文字。感谢 @TKooooo 贡献（PR #24）。

### 图框库与图框录入

- 新增图框时可「套用已有图框」：按当前纸张尺寸筛选库内条目，一键套用字段相对坐标。
- 字段框选对话框改为非模态，可对照红色临时框缩放/平移后再确认；首次显示不再整图重生成，避免复杂图面白块和长时间卡顿。
- 图框录入提示可手动调整打印范围。
- 图框库管理新增「识别图框模式」：按纸张 1:1 比较图名、图号角点相对图纸右下角的位置并归类（相差 1mm 以内视为同一模式）。

### 打印对象线宽与 CTB

- 设置新增「打印对象线宽」。不勾选时按所选打印样式表（CTB）的线宽出图；勾选时颜色、淡显、线型等仍按 CTB，线宽按对象/图层线宽：出图时自动生成所选 CTB 的临时副本（原名`__objlw.ctb`），不修改原 CTB；线宽为“默认”的对象按 CAD 默认线宽（LWDEFAULT，通常 0.25mm）出图。
- 出图时关闭“缩放线宽”，线宽不再随布局设置按打印比例缩放；正式打印、预览、多文件、合并 PDF、DWG 拆图等路径统一生效。
- 点「设置」编辑 CTB/STB 时，中望和 AutoCAD 都向 CAD 取样式表完整路径，与打印使用同一份文件；找不到或无法关联编辑器时打开 `STYLESMANAGER`。
- 多文件批打可按源文件分别选择打印样式。

### 多文件批打

- 非当前打开的 DWG 改为打开并切到活动文档后再出图，避免图号正确但页面全白；预览时先激活源 DWG，结束后切回原图，只关闭本次临时打开的文件。
- 扫描多文件时可勾选模型/布局空间，并提供「当前布局 / 仅模型 / 仅布局」快速勾选；支持按文件夹收集 DWG。
- 带 UCS 的模型空间图框不再打斜：出图前按图框四角或文档 UCS 对齐视图扭转角。
- 多文件批打不再绘制序号红框。
- 多次添加文件改为累加清单：只替换本次成功重扫的「文件 + 空间」，不再清空已有清单。

### 打印速度

- 批打窗口打开后、切换输出格式或打印样式时，在空闲时分步预热打印引擎、设备纸张目录、打印样式表和绘图驱动，消除首张打印卡顿；开始批打前未完成的预热会同步补齐；DWG 输出跳过预热。感谢 @dangfj110 贡献（PR #23）。
- 当前图出图前按布局重生成，同一模型或布局只重生成一次。

### 输出、合并与命名

- 合并 PDF 时可选择保留单张 PDF；合并后的文件名加「_合并」后缀，并始终避开已有文件（自动加 _1、_2…），不再覆盖上一次结果。
- 修复合并 PDF（尤其只有一张图时）完成提示框被进度窗挡住导致界面卡住的问题；修正单张打印时的进度条显示。
- 「完成后打开输出文件夹」覆盖各输出格式（含 DWG）。
- 同一批内重名的输出文件全部按清单顺序从 _1 开始编号（图号_1、图号_2…），图框型、通用型批打和 DWG 拆图一致。
- 加长图图幅命名新增「配置3（倍数）」：A1+1/4 输出 `A1x1.25`，A1+1 输出 `A1x2`，标准图幅命名不变。感谢 @dangfj110 贡献（PR #18）。

### DWG 拆图

- 模型空间拆图改为 Wblock 克隆框内实体并加 XClip 裁剪边界写入新 DWG；布局拆图逻辑不变。
- 带 XCLIP 的块参照按裁剪框判断去留（相交或被包含即保留），避免裁剪块被误删。
- 拆图保存后先恢复原工作数据库再释放新库，提升稳定性。

### 临时红框与高亮

- 打印结束（成功/取消/异常）后清理临时红框与序号，避免中望偶发残留；打印过程中不再改动 CAD 高亮。
- 通用型红框序号按打印顺序编号，与列表编号列一致；高亮跟随选中行与键盘上下移动，只画当前图的红框。
- 序号字高按框宽和字数限制，长图号不再溢出红框；高亮黄框宽度为红框的 1.3 倍。
- 录入图框时的临时标签改用可显示中文的已有文字样式并居中。

### 图纸目录与图号重排

- 图纸目录改用 CAD 原生表格，按文字实际宽度自适应列宽。
- 修复图号重排窗口在 AutoCAD 中确认时可能导致 CAD 中断的问题。

### 设置、界面与稳定性

- 设置文件被占用时自动重试，仍失败则弹窗提示，不再导致 CAD 崩溃；批打窗口只在设置有变化时写回。
- 修复「转图分辨率(DPI)」输入被立刻夹回 600 的问题；线宽选项回读生效。
- 次级对话框统一字号与按钮尺寸，关于/进度窗底部不再被裁切。
- 图框型清单序号不再因列表滚动错位。
